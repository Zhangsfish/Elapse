# Everwhile 宣传片：让时间重新有刻度

日期：2026-10-07
状态：导演执行稿；尚未制作或渲染影片。
用途：社交平台竖屏产品宣传片；不是 App Store App Preview 或送审录屏。

## 1. 创意决定

核心不是“戒掉娱乐”，也不是“把混乱的人生变自律”。

**内容仍然继续，选择仍然属于用户；Everwhile 只是让流逝的时间重新被注意到。**

故事：小说、短剧、视频、社交内容吸走注意力 → 忽然意识不到过去多久 → 选择想留意的 App 与提醒间隔 → 5/10/15 分钟形成可感知的刻度 → 回看今天 → 品牌。

Owner 已接受之前的故事方向，并明确要求：
- 开头拼合看小说、看短剧、看视频、刷社交媒体，但不点平台名。
- 画面高级、节奏有快慢变化。
- Everwhile 出现前可以更快；出现后让时间流逝可见、更规律。
- 导演负责创意决定；Codex 执行，不再让 owner 逐项选择字体/转场/音色。

## 2. 规格与声音

- 18.000 秒；60 fps CFR；1080 帧，索引 0–1079。
- 1080×1920，9:16，SDR；初审 720×1280 同帧率同时间线。
- 英文先完成一条真正有声音的完整粗剪；导演审核后制作中英双语终版。
- 主版不用解释型长旁白。这是本片创意选择，不是继承 Lecture 的旧“无旁白”约束。人声不是当前素材依赖；不为本片另开 TTS/模型安装任务。
- 声音是叙事：前半段密集的内容切换/切分 → 短抽空 → 后半段可预期的时间提示。
- 音乐初稿用同一条 120 BPM 时间基底，前段通过细分、切分和短音增加主观速度；后段减少音符密度，留下稳定脉冲。不是简单整段降速，更不是把旧舒缓 pad 加速。
- 品牌提示音在 7.5 / 9.5 / 11.5 秒出现，三个间距都是 2 秒。它们是剪辑压缩后的演示，不是精确系统通知送达证据。
- 提示音短、清楚、不刺耳，使用自制/有权使用的声音；不是警报，不冒充录到的真实 iOS 通知声。
- 4.25–4.5 秒（15 帧）减少打击乐/低频，保留短尾音；不得让内容画面像被 App 强行暂停。
- 提供 music / SFX 独立 stem；48kHz 工作音频；以约 -15 LUFS、true peak 不高于 -1dBTP 为检查起点，不把达标当好听。
- 真正完整听过才记录听感通过；波形不削波、ASR、文件有音轨均不能代替听感。

## 3. 镜头表

所有帧范围 start-inclusive / end-exclusive；每一镜必须有稳定可读的主要对象。

### S01｜沉浸：0–4.5 秒 / 帧 0–270

不要 Logo 开场，不要四个写着“小说/短剧/视频/社交”的功能图标。

先逐个让人认出内容，再快速拼合：

- 0.0–0.9：小说近景。真实质感的页面、原创短文，轻滚动或翻页。可用原创片段“门外的脚步突然停了下来 / 她没有立刻开门”。不需要读完整段，但不能全部用灰色骨架线假装小说。
- 0.9–1.7：短剧。原创或明确许可的无品牌短镜头：双人对话/门边回望/正反打，允许一条简短原创对白。“短剧”由人的表情和镜头关系说明，不用电视剧海报或现成剧集片段。
- 1.7–2.5：视频。不同于短剧的生活/旅行/手作运动片段，例如食物近景、城市移动镜头。用实际运动素材；不能把一张照片无休止放大冒充视频。
- 2.5–3.3：社交内容。通用照片帖、头像占位与几条原创短句，轻滑动。没有可识别用户名、平台 Logo、标志性专属配色或真实私人聊天。
- 3.3–4.25：先前四种内容回到同一构图，做一次紧凑的分屏/层叠蒙太奇。主要画面仍占大面积，不能堆成四台小手机。节奏逐渐加密但不做全屏闪白、故障抖动、炫技 glitch。
- 2.8–4.5：问题主句已经进入并可稳定阅读。EN：`How long has it been`；ZH：`刚才过去了多久`。
- 4.25–4.5：声音抽空、构图轻收束，留下一个视觉/听觉停顿，准备下一镜。

关键：开头不摆精确秒表、满圈刻度或 0:00→15:00 数字。时间“看不见”是这个开头的感受。内容不断变化，比用一个快进秒表讲道理更有力。

素材策略：先检查已授权的项目素材/本机非私人素材；不足时仅使用有明确许可、可记录来源的通用素材。不要用廉价人物 SVG、灰色方块或陌生网页截图凑高级感。不得采购、订阅、复制热门视频、下载影视剧或翻找 owner 私人媒体。确实缺合格素材时，指出具体缺哪一条，不发散成新的素材平台调研。

### S02｜设定：4.5–6.5 秒 / 帧 270–390

混合内容收束，Everwhile 蓝色时间圆环/圆点成为明确主角。

EN：`Choose your apps` / `Set your interval`
ZH：`选好 App` / `设定间隔`

用经过设计的两枚通用 App 卡片勾选与 `5 min` / `5 分钟` 的设置示意，或已有真实 Release 教学画面，动作有开始与完成，不是一张静态海报做推拉。

五分钟只是本次演示设置；不要暗示产品只支持五分钟。

可以压缩配置操作，但不要凭空生成已授权的系统 picker 或已开启的真实 Home。不要修改 production App 来产生截图状态。

若出现完整手机：保持原始截图内部文字/状态/图表，手机外的构图才是广告编辑层。

### S03｜时间有了刻度：6.5–12.5 秒 / 帧 390–750

**最重要的六秒。**

用户继续看同一批内容。小说还能翻、视频还能播放、帖子还能刷；不能变成屏幕被锁、自动退出、停止娱乐或被强制慢放。

只有“时间层”变得稳定：同一位置、同一字号、同一圆环语言，三个清楚的提醒落点。

- 7.5 秒 / 帧 450：`5 minutes` / `5 分钟`
- 9.5 秒 / 帧 570：`10 minutes` / `10 分钟`
- 11.5 秒 / 帧 690：`15 minutes` / `15 分钟`

三个提示保留至少约 0.8 秒的稳定阅读时间；轻入场、轻退出，不弹跳、不用巨大警告框。

背景在所选 App 之间变化，但共享计时图形不因切 App 重置。无需把每个 App 的数字列成算术题。

用独立的影片图形/现有教学提醒语言表现时间，不制造伪造的 iOS 系统通知历史。

可在该段低层级位置保留一次短标记 `Usage demo · time compressed` / `用时演示 · 时间已压缩`；不得出现大段防御性免责声明，也不能完全依赖 manifest 向观众解释三次提醒只隔两秒。

`A reminder` / `Not a restriction`（ZH `只是提醒` / `不是限制`）可以在本段末尾转场稳定出现，不与巨大的分钟数字同时争抢主标题。以不超过两层主要文字为准。

节奏规律是本片的表达，不承诺 DeviceActivity 或 iOS 通知每次准点；不画秒表和原生悬浮用时条，避免暗示产品具有没有实现的能力。

### S04｜回看：12.5–15.5 秒 / 帧 750–930

镜头落到 Today。

EN：`See where the time went`
ZH：`看看时间去了哪里`

一次看清：Total / by hour / by app（总量 / 每小时 / 各 App）。不逐个弹出三张 PPT 解释。

优先使用仓库现有真实 Release 的 Today 教学示例 raw capture；来源明确是 shipped sample，不是 owner 当天真实数据。保留必要的教学语境，不把它改成伪造 live report。

分钟提醒与 Today 不是同一统计起点。**不能把三次提醒直接变形成 Today 总时长，不能用 callback 数量×间隔计算报告。** 如果现有示例为 30m，保留其真实数字，不重画为15m来追求故事上的假连续性；通过一次明确的页面/视角切换表示“另一项回看功能”，而非本段演示的算术结算。

全片可复用一个蓝色圆点/弧线作为转场物，但不要让该动效暗示报告数据来自提醒计数。

### S05｜落版：15.5–18 秒 / 帧 930–1080

同一个时间圆点/弧线回到实际 Everwhile 图标。

EN：`Feel time passing` / `Nothing else`
ZH：`感受时间流逝` / `仅此而已`

品牌名、实际图标、主句构成完整结尾，从第930帧共同完整显示。不要口号先出，隔两秒再补品牌或下载按钮。最后约2.5秒给阅读，不做无内容拖尾。

影片可视展示文字去句末标点；这是视频排版，不修改 App Store 文案、真实 UI 或源码字符串。

默认交付 brand-only 尾页即可在未上线时评审。另准备可切换的官方 App Store badge 尾页；只有核实对应公开上架页可达、owner授权传播后，才能输出并发布带下载邀请的对外版本。

不要新做 QR、网站、支付或宣传页来扩任务。发布状态不阻塞影片本体制作，但阻止“已经可下载”的错误传播。

## 4. 视觉规则

- 沿用 Everwhile 的冷灰白、蓝色强调、留白与正视手机；内容蒙太奇可拥有真实摄影颜色，不强行把所有小说/人物/食物都染蓝。
- 高级感来自画面占比、镜头衔接、文字重量和声音，不是重阴影、3D转手机、粒子和发光线。
- 先让观众认出真实内容，再加快；不是从第一帧就难以看清。
- 时间圆点/弧线贯穿全片；转场尽量继承同一个对象/滑动方向，不每镜发明一种转场。
- 同一屏最多一个视觉主动作。前段可以内容密集，但主构图稳定；后段时间提示稳定，内容仍可活动。
- 主标题初始字体：英文 Inter Display Semibold（真实600字重/已验证display配置）；中文 Source Han Sans SC Bold（真实700字重）。这是视频display层，不改变冻结商店海报字体。
- 不合成伪粗体，不用 Arial/系统Regular作默认主标题；字体本地固定来源/hash，不提交或分发字体文件。
- 主标题初始84–100px，数字可更大；按真实字体bbox处理行距、字距、断行。禁止为某一镜塞下长句而无声缩小字号。
- 1080画布的关键内容先放在大致x72–948/y144–1632的内部安全区域；这是内部构图起点，不宣称任何社交平台永久统一安全区。实际发片前按目标平台叠层检查。
- 360px宽手机缩略图必须看清主句和分钟数字；辅助文字可以较轻，但不是靠巨大留白配小对象。
- 原始真实 App capture 内禁止重绘；广告图形/内容示意独立记录来源，不能把它们称作系统实录。

## 6. 技术路线

复用已验证的 HyperFrames + paused GSAP + TypeScript + HTML/CSS/SVG + FFmpeg。

本次读到 Lecture package 中已锁定：HyperFrames0.8.132、GSAP3.15.0、TypeScript7.0.2、esbuild0.28.2；这些是参考工程版本，不声称是最新版本。Codex优先复用现有合法可用的隔离工具环境/锁文件，并记录实际运行版本，不开启技术选型或自动升级。

- 不引入第二套 Remotion/React/Three.js/自制浏览器实时录屏引擎。
- 用frame/60统一驱动timeline；没有Date.now、setTimeout推进画面、未固定随机数或渲染时网络素材。
- 视频素材必须按全局帧时间可靠seek；播放录像不是用autoplay赌当前浏览器进度。
- 学习原render命令、workers和编码经验，但按本片18秒/1080帧重新配置；不得照搬26秒常量。
- 本片不需要 TTS 模型或语音API。声音实测从第一版粗剪开始，不是终版才随便贴音乐。
- 素材本地落地，保留来源、许可、SHA。复用Lecture的基础工具代码时留原出处；不复制Lecture专属影片/人声当自己的素材，不改Lecture仓库。

## 8. 导演验收标准

最重要的不是“18秒/60fps都对”，而是这六项：

1. 前3秒能认出至少小说、短剧、视频、社交四种内容，不用写平台名。
2. 4.5秒附近的反差能感受到，后半段不是突然变成助眠广告。
3. 三次时间提示让人建立预期，但观看内容仍然继续。
4. 第三次提示结束时已经懂“累计用时提醒”，不误认墙钟闹铃或单App独立计时。
5. Today与片尾有足够稳定阅读时间；下载/品牌不迟到。
6. 真的像一条有声音设计的产品影片，而不是四张App Store海报加转场。
